# Pixel Avatar 像素分身板块交付包

该目录为独立交付文件，方便使用外部工具（VSCode / Figma / 浏览器 / 像素绘图工具等）进行精细化微调与设计，优化完成后可直接回贴或覆盖回项目。

---

## 📁 包含文件

1. **`PixelAvatar.jsx`**
   - React 组件本体（项目内 `src/components/PixelAvatar.jsx` 的副本）。
   - 包含完整的部件定义、散列伪随机算法（fmix32 + mulberry32）、图层拼装与样式注入。
   - 依赖项仅为 React 及父级传递的 `t`（i18n）、`stats`、`lockedTags`、`onToggleTag`。

2. **`preview.html`**
   - **零依赖独立交互预览页**。
   - 直接用任何浏览器双击打开（或拖入浏览器）即可运行。
   - 支持实时切换 **M / F / N（男/女/中性）**、点击 **换一换** 遍历所有随机组合。
   - 点击 **「复制 SVG」** 或 **「查看 SVG 源码」** 可一键导出当前组合的矢量代码，直接贴入 Figma 或矢量编辑器。

## 📐 像素网格与设计规范

外部工具优化或增改资产时，请遵循以下规范以保证像素比例一致：

| 参数 | 规格 | 说明 |
| :--- | :--- | :--- |
| **viewBox** | `0 0 120 120` | 固定 120×120 像素舞台 |
| **身体中心线** | `x = 60` | 左右严格对称 |
| **最小像素单位** | `2px` / `4px` | 所有直角矩形坐标与宽高建议为 2 的倍数 |
| **抗锯齿** | `shape-rendering: crispEdges` | 强制关闭抗锯齿，保持纯正复古直角像素质感 |
| **图层绘制顺序** | 严格自底向上 | **腿鞋 → 躯干 → 脖子 → 脸底板 → 手臂 → 服装 → 头发 → 五官（眉/眼/腮红） → 嘴巴 → 配饰**<br>*(注：发型刘海不能盖住眼睛；手臂置于服装底层)* |

## 🎨 CSS 动态变量体系

组件与预览页通过 CSS 变量驱动颜色，设计资产时无需写死颜色值，直接引用以下变量：

```xml
var(--skin)       <!-- 肤色：受 M/F/N 外观驱动 -->
var(--hair)       <!-- 发色：受 M/F/N 外观驱动 -->
var(--outline)    <!-- 轮廓黑边：#000000 -->
var(--primary)    <!-- 主风格色：由电影流派驱动（如科幻青 #00ffff、恐怖红 #ff0000） -->
var(--secondary)  <!-- 次风格色：由电影流派驱动（如高光粉 #ff00ff、金黄 #ffd700） -->
var(--accent)     <!-- 强调边框色与投影色 -->
```
